# Perpustakaan Garba Sastra — Offline

Project ini sedang disiapkan sebagai aplikasi Windows portable. Targetnya adalah `Perpustakaan.exe` yang menjalankan PHP dan MariaDB lokal tanpa XAMPP dan tanpa internet.

Build Windows menggunakan GitHub Actions. Source project offline dikemas sebagai `PROJECT_PERPUSTAKAAN-offline.zip`.

Akun awal mode offline: `admin` / `admin`.

Database lokal: `127.0.0.1:3307`.
Web server lokal: `127.0.0.1:8087`.
